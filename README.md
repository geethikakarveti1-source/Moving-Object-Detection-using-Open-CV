# Computer Vision Using Python & OpenCV 🚀

## 📌 About the Project
This project focuses on learning the fundamentals of Computer Vision using Python and OpenCV. It includes practical implementations of image processing, video streaming, and real-time moving object detection.

## 🛠️ Technologies Used
- Python
- OpenCV (cv2)
- Imutils

## 📚 Concepts Covered

### 1. Image Resizing
Resizing images using OpenCV and Imutils to change image dimensions.

### 2. Image Smoothening
Applying Gaussian Blur with different kernel sizes to smooth images and reduce noise.

### 3. Grayscale Conversion
Converting colour images into grayscale for easier image processing.

### 4. Image Thresholding
Applying binary thresholding to convert grayscale images into black-and-white images.

### 5. Video Streaming
Capturing and displaying real-time video using a webcam with OpenCV.

### 6. Moving Object Detection
Implementing motion detection by comparing video frames using:
- Frame capturing
- Grayscale conversion
- Gaussian Blur
- Frame difference
- Thresholding
- Dilation
- Contour detection
- Bounding rectangles

Moving objects are highlighted with rectangular boxes, and a message is displayed when movement is detected.
